# Hafiz Muhammad Ahmad — Portfolio

Personal portfolio website for Hafiz Muhammad Ahmad, a Computer Science student at UET Lahore.

**Live site:** _add your deployed URL here after publishing_

## Built with

- HTML5
- CSS3 (custom properties, no framework)
- Vanilla JavaScript

## Features

- Dark/light theme toggle (remembers your preference)
- Fully responsive (mobile, tablet, desktop)
- Scroll-reveal animations
- Sections: Home, About, Skills, Projects, Education, Achievements, Contact
- Contact form (opens your email client — no backend required)
- GitHub stats embed

## Running locally

No build step needed — just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

This site is a static site and can be deployed for free on GitHub Pages, Netlify, or Vercel.
