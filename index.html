Visibility Report API

A backend REST API that analyzes a local business's online visibility using signals like operating hours, category, description, contact availability, rating, reviews, photos, and competitor rating. It generates a structured report with a rule-based visibility score, an overall evaluation, identified gaps, actionable recommendations, and an estimated potential visibility loss — inspired by a real small-business context.

  • Generates a full visibility report per business
  • Rule-based scoring engine
  • Persists reports to a database (SQLAlchemy + SQLite)
  • Retrieve a report by ID, or list all past reports
  • Input validation with clear error handling
  • Interactive Swagger / OpenAPI documentation
  • Automated test suite with pytest
Python FastAPI SQLAlchemy SQLite Pytest

Bus Ticket Management System

A console-based bus ticketing system in C++ with three distinct roles — Admin, Manager, and Passenger — each with its own login and menu. Models real-world operations like fleet management, seat booking, fare handling, and passenger accounts entirely through core C++ logic.

  • Admin: add/update/delete buses, set fares, view revenue reports, reset accounts
  • Manager: view fleet status, search buses, view booking summaries
  • Passenger: signup/login with validation, book & cancel seats, view profile
  • Filter buses by type, track seat availability in real time
  • Styled terminal UI with colored headers and loading animations
C++ Console I/O Array-based Data Modeling
